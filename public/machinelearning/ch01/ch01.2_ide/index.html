1.2 IDE Configuration#

In Python development, there are two most commonly used Integrated Development Environments (IDEs): one is Jupyter Notebook, and the other is the well-known PyCharm. In this section, we will briefly introduce the usage methods of these two common development tools respectively.

1.2.1 Installation and Usage of Jupyter Notebook#

Jupyter Notebook is a very powerful tool, especially in areas such as data science, scientific research, and presenting complex data analysis projects. Jupyter provides an interactive programming environment that allows us to write and run code, view results, modify code, and then run it again, making experimental analysis and data exploration very simple.Meanwhile, the Jupyter development page also has excellent support for data visualization tools (such as Matplotlib, Seaborn, Plotly, etc.), making it easy to create interactive charts and visualizations. Additionally, Jupyter also supports writing relevant documentation in Markdown format on the development page.

1. Jupyter Notebook Installation

Just like other Python packages, we can directly usepip installto install Jupyter Notebook. It should be noted here that since Jupyter is essentially also a Python software, we can install Jupyter in different Python virtual environments, which means that when we start Jupyter in different environments, the corresponding Python environment is the Python environment where that Jupyter is located.

For example, if we need to install Jupyter in the py38 virtual environment created in the content of Section 1.1.2, then we first need to use the conda command to enter this virtual environment, and then proceed with the installation. The installation command is as follows:

1 conda activate py38
2 pip install notebook

2. Using Jupyter Notebook

After completing the installation of Jupyter, we can directly start it via the command jupyter notebook, which defaults to port 8888. Of course, we can also specify the port through the --port parameter. Meanwhile, if the root user is used, it may fail to start. In this case, the parameter --allow-root can be added to start it. The complete command is as follows:

1 jupyter notebook --ip=0.0.0.0 --port=8778 --allow-root

1.2.2 Installation and Use of PyCharm#

PyCharm is a commercial development software launched by JetBrain. Compared to Jupyter Notebook, the drawback of PyCharm is that the software is too bulky, but PyCharm also has its own advantages. PyCharm provides functions such as code auto-completion, code hints, and syntax highlighting, which can improve coding efficiency and help developers avoid errors.PyCharm also comes with a built-in powerful debugger that supports features such as breakpoints, stepping, and variable inspection, which can help developers more easily find and fix errors in their code. Meanwhile, PyCharm integrates version control systems (such as Git) and the Python Console, providing developers with a comprehensive working environment. It can be seen that PyCharm is more focused on engineering development, while Jupyter Notebook is more focused on Data Analysis and scientific research.

First, you need to go to the official PyCharm website [4] to download the offline installation package. Here, we can choose the free and open-source Community Edition, as shown in Figure 1-20.
